⠿ Site path
  • ← / →, the edge arrows, or a seat chip walk the table. One opponent at a time keeps cards full size.
  • The minion band is shared — every seat's minions, tagged with whose. It never filters, and it survives a second move. Only shared zones carry an owner tag; elsewhere the zone already says whose it is.
  • Cards carry strength/vitality, wound pips, a culture-token count and an attachment fan at board scale — and none of it in a pile, where at ~57px none of it would be legible.
  • Auto · FP · Shadow · All filters the focused seat's own cards. Auto shows a fellowship only while that player holds the Free Peoples role.
  • Chat and the site path are windows — drag by the title bar, resize from the corner, ✕ or Escape to dock. They reopen where and how you left them, and only fade when they cover something that wants attention.
  • ⇄ lays the path left to right. ⊞ opens a seat's piles. ⧉ pops a board into its own window (blocked in this frame — see harness/web/multiwindow_spike.html).
  • A skirmish suspends the focus and draws every participating seat; the arrows go dead rather than lying.
