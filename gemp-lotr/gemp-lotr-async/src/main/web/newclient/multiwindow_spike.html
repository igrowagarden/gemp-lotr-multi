Multi-window spike — detachable opponent boards

Proves the one thing the design depends on: several windows rendering the same game state, with only the main window owning a connection. Press ⧉ on a seat to open that opponent's board in its own window, then press Next phase — every open window repaints from the same store. Nothing here talks to a server; the point is the view topology, not the data.
